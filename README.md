# AKTU Web Technology PYQs – Solutions

This repository contains solutions to **Web Technology laboratory questions** from **AKTU Previous Year Papers (PYQs)**.
The goal is to provide simple, well-structured code examples for students preparing for lab exams and assignments.

---

## 📂 Folder Structure

* `3 vertical column diff bg/` – HTML solutions demonstrating 3-column layouts with different backgrounds.
* `time table/` – Sample timetable project in HTML.
* More solutions will be added unit-wise.

---

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/TarushBajpai/aktu-pyqs-web-technology.git
   ```
2. Open the desired folder in your browser/IDE.
3. Run the `.html` files directly in a web browser.

---

## ✨ Features

* Covers lab-based questions from AKTU PYQs.
* Beginner-friendly HTML and CSS code.
* Organized unit-wise for easy navigation.
